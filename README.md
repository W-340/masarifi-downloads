# مصاريفي | Masarifi — تنزيل أندرويد

المستودع العام **الرسمي لتنزيل إصدارات APK** من تطبيق «مصاريفي». يحتوي هذا المستودع على ملفات التثبيت المنشورة فقط، وليس على أكواد التطبيق أو فواتير المستخدمين أو بياناتهم.

## تنزيل التطبيق

- **[صفحة تحميل مصاريفي](https://masarifi-7ja.pages.dev/download/)**
- **[أحدث إصدار APK على GitHub](https://github.com/W-340/masarifi-downloads/releases/latest)**
- [جميع الإصدارات](https://github.com/W-340/masarifi-downloads/releases)

**حتى نشر أول إصدار رسمي موقّع، قد لا تظهر ملفات APK في الروابط السابقة.** الملفات التجريبية في GitHub Actions الخاصة بالمشروع الأساسي ليست بالضرورة صالحة للتوزيع العام.

## التحديث والإشعارات

عندما ينشر المطوّر إصدارًا جديدًا موقّعًا بنجاح من مشروع «مصاريفي» الخاص، يُرفَع ملف `masarifi.apk` هنا في صفحة **Releases**. عند تهيئة Firebase واشتراك الجهاز في قناة التحديثات وإعطاء إذن الإشعارات، يمكن أن يصل تنبيه بالتحديث مع رابط صفحة التنزيل. وصول الإشعارات قد يتأخر تبعًا لنظام الجهاز واتصاله.

## حماية بياناتك

- خذ **نسخة احتياطية** من مشترياتك قبل الانتقال من نسخة اختبارية إلى نسخة موقعة.
- تثبيت APK جديد فوق إصدار قديم يتطلب **نفس هوية الحزمة ونفس توقيع التطبيق**، بالإضافة إلى رقم إصدار صالح.
- لا تحذف التطبيق المثبّت إلا بعد التأكد من سلامة نسخة احتياطية قابلة للاستعادة.
- لا تشارك النسخ الاحتياطية أو أرقامك السرية في Issues أو أي صفحة عامة.
